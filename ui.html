Tìm kênh Douyin theo tên
          

            

          App mở Douyin (cửa sổ Chrome riêng) để tìm, mất khoảng 10–30 giây.

        

        
        
        
        App Douyin: mở trang kênh → ⋯ → Chia sẻ → Sao chép liên kết. Lần kiểm tra đầu chỉ ghi nhận video hiện có; từ lần sau mới báo video mới.

Gemini API chưa có key

          
Dùng để gợi ý từ khóa tìm kiếm. Lấy key miễn phí ở . Key lưu mã hóa trên máy này.

        
        

          

            
            
            
          

          

        

      

      

        
TMDB API (lịch phim) chưa có key

          
Tab Lịch phim lấy dữ liệu từ TMDB và tự làm mới mỗi 6 giờ. Đăng ký miễn phí ở  → Settings → API, copy API Key hoặc API Read Access Token. Key lưu mã hóa trên máy này.

        

        

      

      

        
Tài khoản chưa đăng nhập

          
Đăng nhập cùng một tài khoản trên các máy: kênh theo dõi, tên kênh, video đã xem được đồng bộ, máy này vừa kiểm tra thì máy kia không kiểm tra lại (không báo Telegram 2 lần).
